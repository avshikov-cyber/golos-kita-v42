# Говорящий телефон

**Управление озвучкой текста на Android-телефоне через ADB.**

---

## Что это

Дашборд на Python, который отправляет текст с компьютера на телефон, и телефон **произносит его голосом**. Всё — через ADB, без облаков, без сторонних приложений.

## Зачем

- Голосовые уведомления из другой комнаты.
- Розыгрыш друзей (телефон внезапно говорит).
- Удалённое управление — телефон может быть где угодно, лишь бы был Wi-Fi.
- Тестовая площадка для будущих голосовых сценариев.

## Как работает

1. Дашборд открывает на телефоне приложение **Text To Speech**.
2. Ставит курсор в поле ввода.
3. Вводит текст через **ADB Keyboard** (Base64, чтобы кириллица не ломалась).
4. Нажимает кнопку «Озвучить».
5. Телефон говорит.

## Что нужно

- Android-телефон с включённым **ADB**.
- **Text To Speech** (Text2Speech от STCodesApp).
- **ADB Keyboard** (com.android.adbkeyboard).
- Python 3.11+.
- Библиотеки: tkinter (стандартная).

## Как запустить

1. Подключить телефон по Wi-Fi: adb connect IP_ТЕЛЕФОНА:5555
2. Проверить связь: adb devices
3. Настроить координаты в talk_center.py под свой экран.
4. Запустить: python talk_center.py
5. Ввести текст, нажать «Озвучить».

## Что умеет

- Озвучивать русский текст (через Base64).
- Работать, когда телефон лежит **экраном вниз**.
- Работать, когда телефон **в другой комнате** (по Wi-Fi).
- Озвучивать текст любой длины.

## Перспективы

- **Интеграция с Голосом** — сказать голосом, телефон говорит.
- **Голосовые уведомления** — телефон сам сообщает о событиях.
- **Расписание** — озвучка по времени.
- **Мульти-устройство** — управление несколькими телефонами.
- **TTS-сервер** — приём текста через HTTP.
